# tz_cotton / python — model pipeline

Spatially explicit LCA + Decent Living Standards assessment of the Tanzanian
cotton value chain. Runs in the conda env **bw25-regional**
(see `environment.yml`).

## Pipeline (restructured 2026-09)

| step | notebook | needs | produces |
|---|---|---|---|
| 00 | `00_setup.ipynb` | ecoinvent 3.12, CF layers | Brightway project + methods |
| 01 | `01_scenarios.ipynb` | 00 | all deterministic tables in `results/tables/` |
| 02 | `02_monte_carlo.ipynb` | 01 | `mc_*` tables (overnight at N=1000; optional) |
| 03 | `03_results.ipynb` | 01 (02 for MC figures) | every manuscript + SI figure |

`04_main.ipynb` executes the four steps in order with per-step flags
(`RUN_MC` defaults to False; the MC-dependent figures in 03 skip politely
when the `mc_*` tables are absent). Log: `results/pipeline_run.log`.

## Where the code lives

- `src/config.py` — project name, method ids, paths. Read its long comment
  on the ecotoxicity method (metals 100-yr sheet, no-LT) before touching it.
- `src/inventory.py`, `src/lca_setup.py`, `src/scenarios.py`, `src/needs.py`
  — foreground inventory, spatial LCA setup, scenario definitions, DLS model.
- `src/monte_carlo.py` — MC engine (also runnable:
  `python -m src.monte_carlo --test`).
- `src/mc_ecotox.py` — resumable ecotoxicity stable-subset MC
  (`python -m src.mc_ecotox`; threshold rationale in the file).
- `src/plotting.py` — every figure. Manuscript figures 1–7 are
  `make_fig1_*` … `make_fig7_*`; SI figures are `make_si_*`; exploratory
  variants `make_fig2b_*` / `make_fig3c_*`. Each function is self-contained
  and reads only `results/tables/` CSVs.

## Conventions

- Water totals exclude the Chemba (TZ0107) basin-CF outlier everywhere.
- Scenario display names come from `results/tables/scenario_display.csv`,
  which is regenerated by `01_scenarios.ipynb` — change names there.
- No figure titles on manuscript figures; captions carry them.

## Data

Foreground data lives in `../data_inventory/cotton_industry_data.xlsx`
(Parameters = raw collected values with sources; Scenarios = per-scenario
derived inputs mirrored as literals in `src/scenarios.py`; DLS_Parameters =
needs.py parameters with sources; Pedigree/Uncertainty = the sigma_ln values
in `src/inventory.py`). `parameters_metadata.ipynb` in the same folder builds
the SI data-provenance figures. Spatial inputs are under `../data_spatial/`,
raw TCB exports under `../data_raw/`.

`attic/` holds superseded scripts and pre-restructure originals — safe to
delete once the next full pipeline run has been verified.
